## macOS

Download the `.dmg` file and open it.

Drag **VP&S Anatomy Viewer** into your **Applications** folder.

Because the application is currently unsigned/not notarized, macOS may
display a message indicating that Apple cannot verify the application or
that the developer cannot be verified.

### Opening the application

Try opening the application normally first.

If macOS blocks it:

1. Open **System Settings**.
2. Go to **Privacy & Security**.
3. Scroll down to the **Security** section.
4. Find the message indicating that **VP&S Anatomy Viewer** was blocked.
5. Click **Open Anyway**.
6. Confirm by clicking **Open** when prompted.

Alternatively, on some versions of macOS you can:

1. Open **Finder → Applications**.
2. Control-click or right-click **VP&S Anatomy Viewer**.
3. Select **Open**.
4. Confirm that you want to open the application.

You should only need to approve the application once.

Do **not** disable Gatekeeper globally.

## Windows

Unzip the VP-S-Anatomy-Viewer-Windows.zip file. Do not run the .exe file, instead
navigate to the installer `.exe` file that is a few folders deep and run that, 

Because the application is currently not code-signed, Microsoft Defender
SmartScreen may display:

> **Windows protected your PC**

If you trust the downloaded application:

1. Click **More info**.
2. Verify that the application is **VP&S Anatomy Viewer**.
3. Click **Run anyway**.
4. Continue through the installer.

Some university, hospital, or corporate-managed Windows computers may
prevent users from running unsigned applications. If **Run anyway** is not
available, your organization's security policy may be blocking the
application. In that case, contact your IT administrator.

Do **not** disable Microsoft Defender or SmartScreen globally.

## Using the Viewer

The application includes example CT datasets that can be selected from the
dataset and scan menus.

### Segmentation controls

The segmentation panel allows you to:

- Toggle individual anatomical structures on or off
- Search for structures by name
- Show all structures
- Hide all structures
- Click a structure name to isolate it
- Adjust segmentation opacity

## Intended Use

VP&S Anatomy Viewer is intended for research, education, visualization, and
software demonstration.

It is not validated as a medical device and should not be relied upon for
clinical diagnosis or treatment decisions.
